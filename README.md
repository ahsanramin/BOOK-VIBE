# 🚀 Book Vibe - Ultra Premium Colorful SaaS Platform

![Book Vibe](https://i.ibb.co.com/khHN7Pk/9780143454212.jpg)

## 🌟 Overview
Book Vibe is an award-winning, hyper-interactive SaaS web application built for book lovers. It features a custom WebGL-feeling mouse cursor, 3D interactive book cards, dynamic mesh gradients, and a fully functional dashboard with data visualization.

## ✨ Features
- **Vibrant UI/UX:** Deep glassmorphism, rainbow hover borders, animated mesh gradients, and neon glows.
- **State Management:** Fully functional Read and Wishlist system using React Context API.
- **Advanced Analytics:** Interactive AreaCharts using Recharts.
- **Dark/Light Mode:** Seamless theme switching with `next-themes`.
- **100% Responsive:** Pixel-perfect design across mobile, tablet, and desktop.

## ⚙️ Tech Stack
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Recharts & Lucide React

## 🛠️ Installation
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`
